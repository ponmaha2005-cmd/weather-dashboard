# Weather Dashboard

A React app to check the weather of any city.

## Features
- City search with autocomplete suggestions
- Current weather: temperature, feels like, humidity, wind, pressure, sunrise and sunset
- Next 24 hours and 7-day forecast with day and night icons
- Use my current location
- Save favorite cities (stored in the browser)
- Light and dark mode
- Switch between °C and °F
- Uses the free Open-Meteo API (no API key needed)

## Tech Used
React, Vite, JavaScript, CSS, Open-Meteo API

## Run Locally
```
npm install
npm run dev
```
